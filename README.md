# Indoor Navigation App

A web-based indoor navigation project developed to help students and visitors find locations inside our college.

## About the Project

Finding classrooms, departments, and other locations inside a college building can be confusing, especially for new students and visitors. This project aims to make it easier to explore the campus through an indoor map and QR code-based navigation.

The application has different user roles with different levels of access to improve security and manage the available features.

## Features

- Indoor map for navigating college locations
- QR code-based navigation
- Separate interfaces for different user roles
- Admin panel with full access to the available management features
- Candidate login using a hall ticket number
- Admin login using an ID
- Limited access for visitors, candidates, and freshers

## User Roles

- **Admin:** Has full access to the available features and management functions.
- **Candidate:** Logs in using a hall ticket number and has access to the features provided for candidates.
- **Visitor:** Has limited access to the navigation features.
- **Fresher:** Has limited access to the available features.

## Technologies Used

- HTML
- CSS
- JavaScript
- MapLibre GL JS

## How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Run the application using the Live Server extension or the method supported by the project.
4. Open the relevant page and explore the available features.
