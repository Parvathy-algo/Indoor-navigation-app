# Indoor Navigation App

An indoor navigation web application developed to help students and visitors find their way around our college campus.

## About the Project

Finding a particular room or department inside a college building can sometimes be confusing, especially for new students and visitors. This project aims to make indoor navigation easier by providing a simple web-based interface to help users find locations within the campus.

## Features

- Indoor map for navigating college locations
- QR code-based navigation
- Separate interfaces for different user roles
- Admin panel for managing navigation information
- Simple interface for finding locations inside the college

## Technologies Used

- HTML
- CSS
- JavaScript
- MapLibre GL JS

## How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open the main HTML file in your browser, or use the Live Server extension in VS Code if the project requires it.
4. Explore the available pages and navigation features.
